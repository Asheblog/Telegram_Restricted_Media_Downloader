# Spec: 叶子摘要优先领先井号

## Goal

改善 Source Post Archive Path 叶子段 `{message_id} - {正文摘要}` 的命名，使「主题标签 + 评论区导流」类主贴不再落入「进入评论区置顶查看资源」等垃圾名；同时不污染 Post Author / `archive_by_author`。

## Requirements

1. **硬标题优先**：`【…】` / `数字. 标题` 仍压过井号与普通正文。
2. **领先井号**：跳过套话/CTA/署名/日期/纯 emoji 后，若**首个可用内容行**为纯 `#标签` 行，叶子摘要取该行第一个非站点/题材黑名单标签（形如 `#情侣日记`）。
3. **文末标签不压正文**：正文标题在前、主题标签在后的频道（如署名频道）仍用正文行作摘要。
4. **导流句降权**：`进入评论区…`、`推荐指数`、`置顶查看资源` 等不得成为摘要。
5. **作者层不变**：Post Author 仍只认署名行；井号摘要不得写成作者夹；无署名 + `archive_by_author` 仍为 `_未知作者`。
6. **实现落点**：逻辑集中在 `module/source_folders.py` 的标题选择（`pick_best_title_line` / `score_title_line` / normalize），不在转存链路各处分叉。

## Out of scope

- 评论区深链取片可靠性
- 历史归档整理的作者回连启发式
- 已冻结叶子名的回写
